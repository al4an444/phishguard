# Política de seguridad

Si encuentras una vulnerabilidad en PhishGuard (por ejemplo, una entrada que provoque un cuelgue,
consumo excesivo de recursos o XSS en la interfaz web), **no abras un issue público**.
Usa el reporte privado de GitHub: pestaña *Security* → *Report a vulnerability*.

Las URLs que PhishGuard no detecta correctamente no son vulnerabilidades: repórtalas con la
plantilla *Falso positivo / falso negativo*.
